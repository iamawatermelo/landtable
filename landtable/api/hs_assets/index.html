landtable

Example Landtable Application

Landtable is a database proxy designed to make developing applications easier. It's not finished yet, but you can play with a demo here. Note that this Landtable workspace uses an in-memory database, so your data will not be stored forever.

This demo was built with:

  • Landtable Core
  • FastAPI
  • htmx
  • Perspective API
  • Tears

You should go read the README.md to find out more about how Landtable works and how it may be useful to you in the future.

You can also look at the marketing website that was created for Landtable.
